根目录作为单仓顶层，通过 vite.config.ts 注入 @vitejs/plugin-react 与 @tailwindcss/vite，并将 package.json 的 version 编译为 __APP_VERSION__ 常量供全仓读取；package.json 同时声明 Electron（electron-vite/electron-builder）与 Capacitor（@capacitor/*）依赖，使同一份 src/ 代码可同时被 Web、桌面与 Android 复用。app_shell 子模块提供 React 根入口与 MainLayout 路由切换，android_capacitor 子模块在同一个工程中引入原生桥能力并通过 Capacitor CLI 生成 Android 壳；业务数据访问统一收敛到 src/db/ 基于 idb 的仓库层，跨模块能力集中在 src/services/ 暴露，配置集中在 src/config/ 按领域拆分。TypeScript 采用多项目引用模式（tsconfig.app.json + tsconfig.node.json），由根 tsconfig.json 聚合，配合 eslint.config.js flat config 保证全仓风格一致。ImageGenAPI/ 与 docs/ 作为前后端协作契约与重构文档的补充，不参与构建但被根脚本引用。
