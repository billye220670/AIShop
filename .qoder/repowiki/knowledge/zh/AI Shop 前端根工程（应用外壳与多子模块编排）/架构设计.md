根工程以 `main.tsx` 为唯一入口挂载 React 应用，通过 `vite.config.ts` 启用 @vitejs/plugin-react 与 @tailwindcss/vite，并将 `package.json` 中的版本注入为 `__APP_VERSION__`；所有业务子模块（chat/image/artifact/settings/music/video/usage）共享 `src/config/` 下的模型、主题、提示词与版本配置，通过 `src/db/` 基于 idb 的统一仓库层持久化对话、消息、上下文、收藏与图片历史，由 `src/services/` 提供 API 调用、备份、文件解析、搜索判断、用量统计等跨模块服务；ESLint 使用 flat config 统一校验全部 `.ts/.tsx`，TypeScript 采用多项目引用模式（`tsconfig.app.json` + `tsconfig.node.json`），构建脚本 `build: tsc -b && vite build` 保证类型检查先于打包。
