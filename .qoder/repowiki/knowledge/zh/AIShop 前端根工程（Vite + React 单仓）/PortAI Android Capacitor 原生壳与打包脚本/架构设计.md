模块由三部分组成：
- Android Gradle 工程（android/）：顶层 build.gradle + variables.gradle 集中声明 compileSdk/targetSdk/minSdk（36/36/24）与依赖版本；settings.gradle 引入 :app 与 :capacitor-cordova-android-plugins 两个子模块；app/build.gradle 通过 apply from: 'capacitor.build.gradle' 接入 Capacitor 生成的插件依赖（camera/filesystem/haptics/share/status-bar/file-picker），并可选启用 google-services 插件。
- 应用入口 MainActivity.java：继承 com.getcapacitor.BridgeActivity，在 onCreate 中通过 addWebViewListener 注册 onPageStarted/onPageLoaded 回调，并在 DecorView 上监听 WindowInsetsCompat 以注入 CSS 变量 --native-inset-top/bottom/--native-ime-inset-bottom，替代 Capacitor SystemBars 自动 inset 处理（capacitor.config.ts 中已禁用 insetsHandling）。
- JS↔Native 桥：通过 addJavascriptInterface 暴露四个内部类——HapticBridge（系统触感 KEYBOARD_TAP/CONTEXT_CLICK）、InputStateBridge（同步 focused input type 用于密码框长按分流）、ClipboardBridge（ClipboardManager 读取剪贴板并以 evaluateJavascript 回调 JS）、LocationBridge（ACCESS_COARSE/FINE_LOCATION 权限申请后通过 LocationManager 获取经纬度，首次拒绝不再重复弹窗，前端降级 IP 定位）。所有桥均用布尔 flag 保证幂等注册。
- 资源与配置：AndroidManifest.xml 声明 MainActivity（singleTask/exported=true）、FileProvider、INTERNET/VIBRATE/CAMERA/LOCATION 权限；assets/capacitor.config.json 与根目录 capacitor.config.ts 双端同步 appId/appName/webDir/SystemBars 配置；res/ 下提供多密度 splash 与 mipmap 图标。
- 开发流水线脚本（根目录 install-apk*.bat/.ps1）：.bat 仅作为 PowerShell 入口，install-apk.ps1 提供交互式菜单（是否跳过构建），install-apk-auto.ps1 无交互自动安装并启动；两者均实现 Find-Adb/Find-Jdk21/Assert-ExitOk 工具函数，流程为 npm run build → npx cap sync android → gradlew assembleDebug → adb install -r → am start。
