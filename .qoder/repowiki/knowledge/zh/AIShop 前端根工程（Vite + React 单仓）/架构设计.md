根目录作为单仓库顶层，通过 `main.tsx` 挂载 React 应用并由 `vite.config.ts` 注入 `@vitejs/plugin-react`、`@tailwindcss/vite`，将 `package.json` 版本编译为 `__APP_VERSION__`；所有业务子模块共享 `src/config/` 下的模型、主题、提示词与版本配置，数据访问统一收敛到 `src/db/` 基于 idb 的仓库层，跨模块能力集中在 `src/services/` 提供；Android 端通过 `@capacitor/*` 依赖在同一个工程中引入原生桥能力，由 `android_capacitor` 子模块负责 WebView 封装与 JS-Native 交互；ESLint flat config 与多项目 TypeScript 引用（`tsconfig.app.json` + `tsconfig.node.json`）保证全仓类型与风格一致，构建脚本 `build: tsc -b && vite build` 强制先类型检查再打包。根目录还附带 `ImageGenAPI/` 参考文档与 `.env.example` 等环境说明，作为前后端协作契约的补充。
