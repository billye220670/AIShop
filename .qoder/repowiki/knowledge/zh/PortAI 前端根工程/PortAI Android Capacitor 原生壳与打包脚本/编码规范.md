- JS↔Native 桥统一采用 private class + @android.webkit.JavascriptInterface 注解的方式，并通过 boolean flag（如 hapticBridgeRegistered）保证 addJavascriptInterface 的幂等注册。
- 原生向 JS 回传数据统一通过 WebView.evaluateJavascript 调用挂在 window 上的回调函数名，并使用 String.format(Locale.US, ...) 拼接 JSON/数值参数以保证跨区域数字格式一致。
- 需要主线程执行的 UI/WebView 操作一律通过 wv.post { ... } 或 View.post 切换到主线程后再调用 evaluateJavascript。
- Gradle 依赖版本集中在 root 的 variables.gradle 中以 ext 形式声明，app/build.gradle 通过 rootProject.ext 引用，避免硬编码版本号。
- 构建脚本将 adb/JDK 查找逻辑封装为独立函数（Find-Adb/Find-Jdk21/Test-Jdk），并用 Assert-ExitOk 统一处理非零退出码的错误提示与退出。
