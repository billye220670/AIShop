根工程通过 `main.tsx` 作为唯一入口挂载 React 应用，由 `vite.config.ts` 注入 `@vitejs/plugin-react`、`@tailwindcss/vite` 并将 `package.json` 中的版本编译为 `__APP_VERSION__`；所有业务子模块共享 `src/config/` 下的模型、主题、提示词与版本配置，数据访问统一收敛到 `src/db/` 基于 idb 的仓库层，跨模块能力（API 调用、备份、文件解析、搜索判断、用量统计等）集中在 `src/services/` 提供；ESLint flat config 与多项目 TypeScript 引用（`tsconfig.app.json` + `tsconfig.node.json`）保证全仓类型与风格一致，构建脚本 `build: tsc -b && vite build` 强制先类型检查再打包。
