- 所有 TypeScript/TSX 文件通过根目录 eslint.config.js flat config 统一校验，启用 js/recommended、typescript-eslint recommended、react-hooks rules 与 react-refresh。
- TypeScript 采用多项目引用模式，app 与 node 环境分别维护 tsconfig.app.json 与 tsconfig.node.json，由根 tsconfig.json 聚合。
- 业务数据统一通过 src/db/ 下的 repo 层访问 idb，组件不直接操作 IndexedDB。
- 跨模块共享的配置（模型、主题、提示词、版本）集中在 src/config/ 下按领域拆分导入。
