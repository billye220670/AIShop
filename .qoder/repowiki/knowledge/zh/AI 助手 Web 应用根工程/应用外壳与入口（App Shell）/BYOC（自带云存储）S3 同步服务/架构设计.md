模块以 `index.ts` 为统一入口，向上暴露配置读写、连通性测试、`syncNow`（双向增量）、`backupNow`/`restoreNow`（全量备份）、状态查询与 `scheduleAutoSync`（自动调度）等 API；内部按职责分层：`s3Client.ts` 提供零依赖 AWS SigV4 客户端，封装 PUT/GET/HEAD/DELETE/ListObjectsV2 五种操作并处理 path-style/virtual-hosted URL 构造与 CORS/鉴权错误；`incrementalSync.ts` 基于 `SyncManifestV1` 清单做增量推拉，配合 `state.ts` 中的本地 tombstone 机制传播删除；`backupSync.ts` 独立于增量层实现全量归档；`types.ts` 集中定义 `ByocConfig`、`SyncManifestV1`、`SyncResult` 等跨文件契约；`state.ts` 在 IndexedDB 的 kv store 中持久化 deviceId、云端清单缓存、本地 tombstone 与 lastSyncAt。依赖方向单向：`index → {incrementalSync, backupSync, state} → s3Client → utils/sha256`，上层不感知底层签名细节。自动同步通过 `navigator.locks` 串行化多标签页并发，并以 `setInterval` + `visibilitychange` 驱动静默重试。桶内布局约定在 `sync/v1/` 下分目录存放 manifest、convs、msgs、nodes、blobs、history/favs/roles 及其 index.json。
