- 对外 API 统一先调用 `validateConfig` 校验必填字段（endpoint/bucket/accessKey/secretKey），缺失则抛出带中文提示的错误后再进入网络逻辑。
- 所有 S3 请求经 `createS3Client` 构造的 `request` 函数统一签名、编码与错误包装，调用方只关心 put/get/head/delete/list 语义。
- SHA-256/HMAC 计算在 `s3Client.ts` 中通过 `hasSubtle()` 动态选择 WebCrypto 或 `utils/sha256.ts` 的纯 JS 实现，保证浏览器非安全上下文可用。
- 增量同步采用「清单 + tombstone」模型：推送重写完整 `SyncManifestV1`，删除通过 tombstones 列表传播，避免依赖缓存一致性。
- 自动调度以 `safeSync` 为唯一执行点，捕获异常仅 `console.warn` 不打断主流程，并通过 `BYOC_STATUS_EVENT` / `BYOC_SYNC_DONE_EVENT` CustomEvent 通知 UI 刷新。
- 配置项集中在 `types.ts` 的 `DEFAULT_BYOC_CONFIG` 与 `BYOC_PROVIDER_PRESETS` 中维护，新增服务商只需扩展预设记录。
